# P&L агент — ТОО «Штокпром» (вариант по проектам)

Загрузка выгрузки 1С ОСВ → P&L с блоками по проектам.

**Структура P&L:**
- На каждый проект — блок: Доход → Прямые расходы (по статьям) → Операционная прибыль.
- Порядок блоков: NCOC → NCOC TAR → прочие.
- Ниже: административные (7211, налоги с ЗП свёрнуты), прочие дох/расх,
  налогооблагаемый доход (без 7212), КПН 20 %, чистый доход,
  блок 7212 (не на вычет) ниже чистого, контроль сверки с 1С (Разница = 0).

**Разметка проектов** — в `canon_project()` (файл `shtok_engine.py`):
теги 1С сводятся к имени проекта; перекинуть доход/статью в другой блок —
одна строка.

# P&L агент — ТОО «Штокпром»

Streamlit-приложение: загрузка выгрузки 1С ОСВ → P&L.
Доход по контрагентам, прямые затраты по статьям, админ (7210/7211) расшифрован,
7212 отдельным блоком ниже чистого дохода, налоги с ЗП свёрнуты, курсовая разница нетто.
Сверка с 1С (контроль «Разница» = 0).

## Файлы
- `app.py` — интерфейс (Main file path для Streamlit)
- `shtok_engine.py` — парсер ОСВ + генератор P&L + журнал
- `recalc_native.py` — пересчёт формул
